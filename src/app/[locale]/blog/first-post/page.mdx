# Why MDX for a developer blog

MDX is **Markdown + JSX**. It lets you write clean Markdown while embedding React components
where you need interactive demos, callouts, or data-driven content.

## Why it matters here

This portfolio has structured data for projects and a growing set of reusable UI patterns.
MDX gives me a way to reuse those patterns in writing without giving up the simplicity of Markdown.

## The plan

- Keep the main blog listing and routes in Next.js App Router
- Store posts as `.mdx` so they can include charts, images, or custom components
- Add localized posts later by mirroring folders per locale
